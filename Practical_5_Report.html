1. Practical Objective & Overview
Objective: To connect a NoSQL MongoDB database to an Express server using Mongoose ODM, enforce strict data validation via a Mongoose Schema, replace in-memory data structures with async database model queries, and return structured JSON for validation/cast errors.

In Practical 4, task data was stored transiently in an in-memory JavaScript array. Practical 5 upgrades the backend to persist data permanently in a local MongoDB database instance using Mongoose. Mongoose provides schema validation (required fields, trim, data types, default values) before any document is written to MongoDB.

2. System Architecture & Schema Design

The updated Express application communicates through Mongoose ODM to query the tasks collection in MongoDB:

3. Code Implementation Highlights

A) Database Connection Module (backend/config/db.js):

import mongoose from 'mongoose';

const connectDB = async () => {
  try {
    const conn = await mongoose.connect(process.env.MONGO_URI || 'mongodb://127.0.0.1:27017/studentportfolio');
    console.log(`🌿 MongoDB Connected: ${conn.connection.host}/${conn.connection.name}`);
  } catch (error) {
    console.error(`❌ MongoDB Connection Error: ${error.message}`);
    process.exit(1);
  }
};
export default connectDB;

B) Mongoose Schema & Model Definition (backend/models/Task.js):

import mongoose from 'mongoose';

const taskSchema = new mongoose.Schema({
  title: { type: String, required: [true, 'Task title is required'], trim: true },
  description: { type: String, trim: true, default: '' },
  completed: { type: Boolean, default: false },
  createdAt: { type: Date, default: Date.now }
}, { versionKey: false });

const Task = mongoose.model('Task', taskSchema);
export default Task;

C) Custom Mongoose Error Handler Middleware (backend/middleware/errorHandler.js):

const errorHandler = (err, req, res, next) => {
  let statusCode = res.statusCode && res.statusCode !== 200 ? res.statusCode : 500;
  let errorMessage = err.message || 'Internal Server Error';

  // 1. Handle Mongoose CastError (Invalid ObjectId)
  if (err.name === 'CastError') {
    statusCode = 400;
    errorMessage = `Invalid resource ID format: '${err.value}' is not a valid MongoDB ObjectId`;
  }

  // 2. Handle Mongoose Schema ValidationError
  if (err.name === 'ValidationError') {
    statusCode = 400;
    const messages = Object.values(err.errors).map(val => val.message);
    errorMessage = `Schema Validation Error: ${messages.join(', ')}`;
  }

  res.status(statusCode).json({ success: false, status: statusCode, error: errorMessage });
};
export default errorHandler;
