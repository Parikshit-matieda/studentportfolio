1. Practical Objective & Problem Definition
Title: AI API Integration into a Web Application
Objective: To integrate an external AI service into the existing application and understand responsible AI usage.
Problem Statement: Add an AI-powered feature to the Task Management application using the OpenAI API (or an alternative such as Gemini API). The feature must serve a meaningful purpose — for example, auto-generating task descriptions, prioritizing tasks, or suggesting deadlines based on task title. Handle API errors gracefully and ensure the AI feature degrades without breaking the core application.

As cloud software engineering advances into the AI era, web applications integrate Generative AI foundation models to automate cognitive workflows. However, production deployments must adhere to Responsible AI Engineering: external AI APIs introduce non-deterministic latency, rate limits (HTTP 429), quota exhaustions, billing boundaries, and network outages. Modern web architectures must implement resilient circuit breakers and Graceful Degradation so that core business transactions (such as task management) remain 100% available and operational regardless of third-party AI provider availability.
