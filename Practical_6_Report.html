1. Practical Objective & Overview
Objective: To wire the React Single Page Application frontend to the Node.js / Express REST API and MongoDB database into a fully functional, real-time full-stack web application with asynchronous CRUD workflows and persistent storage.

In Practical 6, the React portfolio UI is connected directly to the Express + MongoDB backend developed in Practicals 4 & 5. The application provides an interactive Task Management interface allowing users to view, create, update, and delete task documents stored in MongoDB via asynchronous API calls. Data persistence is guaranteed across browser reloads.

3. Code Implementation Highlights

A) API Service Layer (src/services/taskApi.js):

const API_BASE_URL = 'http://localhost:5000/tasks';

// GET All Tasks
export const fetchTasks = async () => {
  const response = await fetch(API_BASE_URL);
  if (!response.ok) throw new Error('Failed to fetch tasks from backend');
  return await response.json();
};

// POST Create Task
export const createTask = async (taskData) => {
  const response = await fetch(API_BASE_URL, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(taskData)
  });
  return await response.json();
};
