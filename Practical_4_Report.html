1. Objective & Problem Definition

Objective: Design and implement a RESTful backend server with complete CRUD endpoints using Express middleware pipeline.

Problem Statement: Build a Node/Express backend for a Task Management system. Implement REST endpoints for creating, reading, updating, and deleting tasks (using an in-memory array). Apply request logging middleware (method, URL, timestamp) and a global error handling middleware as the last step in the pipeline. Ensure appropriate HTTP status codes (200, 201, 400, 404, 500).

2. Middleware Pipeline Architecture
Client Postman / Browser / Curl
➔
[Logging Middleware] Timestamp + Method + URL
➔
Express Router CRUD Handlers (/tasks)
➔
[Global Error Handler] 500 Status JSON Response
3. Server & Middleware Code Implementation

A) Request Logging Middleware (backend/middleware/logger.js):

const requestLogger = (req, res, next) => {
  const timestamp = new Date().toISOString();
  console.log(`[${timestamp}] ${req.method} ${req.originalUrl}`);
  next();
};
export default requestLogger;

B) Global Error Handling Middleware (backend/middleware/errorHandler.js):

const errorHandler = (err, req, res, next) => {
  const statusCode = res.statusCode && res.statusCode !== 200 ? res.statusCode : 500;
  console.error(`[GLOBAL ERROR HANDLER] ${err.message}`);
  res.status(statusCode).json({
    success: false,
    status: statusCode,
    error: err.message || 'Internal Server Error',
    timestamp: new Date().toISOString()
  });
};
export default errorHandler;

C) Express Server Assembly (backend/server.js):

import express from 'express';
import cors from 'cors';
import requestLogger from './middleware/logger.js';
import errorHandler from './middleware/errorHandler.js';
import taskRoutes from './routes/taskRoutes.js';

const app = express();
app.use(cors());
app.use(express.json());
app.use(requestLogger); // 1. Custom Logging Middleware

app.use('/tasks', taskRoutes); // 2. Express Router

app.use(errorHandler); // 3. Global Error Handler (Last in pipeline)
